# Time Tracking App

## Ziel des Projekts

Diese App ist ein Prototyp für eine Arbeitszeiterfassung mit Rollenmodell, Ein- und Ausstempeln, Monatsberichten und digitaler Quittierung.

Das Projekt dient dazu, objektorientierte Programmierung mit Python und JavaScript praktisch zu demonstrieren.

## Kernfunktionen

- Ein- und Ausstempeln
- Rollenmodell: Admin, Geschäftsführung, Abteilungsleiter, Mitarbeiter
- Berechtigungsprüfung
- Monatsübersicht
- Monatsbericht
- Quittierung per Code
- Audit-Log
- Responsive Frontend für PC und Smartphone
